# Used Vehicle Valuation Engine

An end-to-end Machine Learning pipeline developed in Google Colab to predict used vehicle valuations based on vehicle specifications, mileage, brand, and depreciation trends.

---

## Overview
- **Objective:** Build a regression model to estimate market pricing for pre-owned vehicles.
- **Workflow:** Exploratory Data Analysis (EDA), missing value handling, feature encoding, model training, and performance evaluation.
- **Environment:** Google Colab / Python 3

---

## Tech Stack & Libraries
- **Language:** Python
- **Data Manipulation:** Pandas, NumPy
- **Visualization:** Matplotlib, Seaborn
- **Machine Learning:** Scikit-Learn

---

## Getting Started
1. Open the notebook file `Used_Vehicle_Valuation_Engine.ipynb` in this repository.
2. Click **Open in Colab** at the top of the file view, or run it locally using Jupyter Notebook.
